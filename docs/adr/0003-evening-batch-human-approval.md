# Evening routing batch requires human approval

Capture (Telegram primary) lands in Capture Queue. At ~6pm the Routing Batch classifies items and produces Proposals. Nothing is filed, no calendar event is created, and no commitment is added without explicit approval.

Dual approval channels: Telegram summary and IDE trigger ("reflect for today, I took a walk"). Proposals are persisted in vault log (and optional Obsidian dashboard note), not ephemeral chat.
