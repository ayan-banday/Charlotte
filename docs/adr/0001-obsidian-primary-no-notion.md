# Obsidian as primary workspace; Notion phased out

Knowledge stays in markdown vault. Notion is not the command center and not a knowledge store. It locks editing, increases token cost for agents, and Ash finds it clunky on laptop.

Obsidian is the human workspace: browse context, Gantt/calendar views via community plugins, graph view. Execution stays in IDE (Cursor, Claude Code, Codex). Google Calendar holds commitments as timed events, not task lists.
