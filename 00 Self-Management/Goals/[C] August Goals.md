# August 2026 Goals

**Q3:** Build founder-relevant proof through the playable Udyaan course, Udyaan operations, and technical/product judgment.

---

## August Objective: Make the Udyaan From Idea to Business course v0 buildable

The Udyaan From Idea to Business course v0 is the playable learning layer for Udyaan's *From Idea to Business* course. August does not require a full course or a large student launch. It requires enough product, technical, team, and resource clarity that the first usable alpha can ship in September.

### Key Result 1: v0 product and learning specification is complete

- [ ] [[C] Udyaan From Idea to Business v0 Schematics]] explains the context, student, first mission, core learning loop, curriculum logic, game mechanics, required screens, success measures, and explicit non-goals.
- [ ] The first mission has a lesson, real-world task, artifact, feedback rubric, and unlock condition that a new curriculum contributor can use without extra context.

### Key Result 2: Technical foundation is chosen and challenged

- [ ] Hold architecture reviews with professors and engineers using the questions in the course v0 schematics.
- [ ] Confirm or revise the starting architecture, data model, access rules, API/action list, deployment path, collaboration workflow, and alpha test plan.
- [ ] Create the GitHub repository and deploy one thin end-to-end vertical slice for review.

### Key Result 3: The first operating team is ready to build

- [ ] Finalise role briefs, selection criteria, decision rights, weekly outputs, and meeting cadence for the initial intern team.
- [ ] Start intern hiring through the university: source candidates, run relevant small assessments, and prepare onboarding for selected contributors.

### Key Result 4: v0 resources and costs are understood

- [ ] Build the first resource and cost model for alpha, first cohort, and larger cohort scenarios.
- [ ] State people, software, AI-feedback, infrastructure, human-review, acquisition, and risk assumptions, including what the university supplies.

### Key Result 5: Time is visible and directed to the real work

- [ ] Record five daily data points this week: wake time, first meaningful block, stimulation time, Udyaan course shipment, and tomorrow's first task.
- [ ] Run a weekly review that reallocates the next week from the evidence.
