**Two Most Important Mechanisms**

- **Open loop theory:** Incomplete work (half-written sentence, started task) forces continuation not initiation. Cold starts are ADHD-expensive. Open loop eliminates transition cost. Execution happens in existing momentum, not new.
- **Regulation cycles (operating system):** Dysregulation is not a problem to solve. It's a phase in a cycle: regulated → activity → dysregulate → regulate again. Day is structured by intentional cycling, not fighting dysregulation. Calendar structure (work blocks) drives behavior more than willpower.

**Experiments**

- **Prep + open loop:** Prep block identifies blockers (ICP, structure, mind map). Then write one open sentence/section same day. Tomorrow: continuation only (not cold start).
- **Strategic dysregulation:** YouTube → regulation protocol (oxytocin, movement) → open loop to escape dysregulation (reading, work becomes exit strategy).
- **Time blocking by focus type:** Mornings = deep work only. Afternoons = prep only. Eliminates context-switching cost.
- **Quick pre-study formula:** 15–20 minutes big picture (parts, how they fit, basic flow). Enough to start building. Learning happens in building, not studying first.
- **Calendar audit:** Identify insufficient work blocks. Add execution blocks (not prep). Empty queue creates decision points.
