## 2. Learning methodology

Loop for each course, run **alongside** the syllabus (not instead of it).

1. **Before material:** Name skill gaps for that semester.
2. **Map:** Learning outcomes + assigned material against gaps; study independently.
3. **Apply:** Where a concept connects to Udyaan or another live project, use it directly.
4. **Check in:** Every 1–2 weeks (~2 courses at a time) — presentation or structured email to relevant teacher. Feedback surfaces gaps; revise next cycle or move on if closed.
5. **Assess:** Same rhythm, aligned with cohort coverage.
