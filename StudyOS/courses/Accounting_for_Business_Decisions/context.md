## 4. Default gap-closure type

Default type: **`quantitative`** `[INFERRED]`

Reasoning: the objective is *producing the formats correctly and repeatedly*. `spec.md` §2 is
explicit that reading never closes a quantitative gap — variants must be solved until mechanical
(5 variants, zero hesitation, correct method every time). That is exactly the bar the student asked
for, so it is the honest default.

**Known friction, recorded rather than smoothed over:** this course has one topic covering both
mechanics (journal → ledger → trial balance) and concepts (going concern, conservatism, materiality).
`spec.md` allows a type override per **topic**, not per **cluster** — and this topic is one cluster by
the student's explicit instruction. So the concept nodes inherit `quantitative` and will close by
solving variants — applying a convention to 5 fresh scenarios rather than restating it. That is a
defensible fit and arguably a better test than an `applied` worked example would be, but it is a
stretch of the type, not a clean match. Flagged so nobody later reads it as an accident.
