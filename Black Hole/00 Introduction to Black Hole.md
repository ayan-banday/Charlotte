# Black Hole

Single routed sink for **agent and Manus AI build output** — decks, PDFs, slide exports, scratch builds.

## Rules

1. **All** Manus AI deliverables land here first: `Black Hole/<date>-<slug>/`
2. IDE agents writing PPTX/PDF/PNG scratch use the same folder
3. **Finished** markdown (drafts, specs, brain dumps) go to `02 Projects/` — not here
4. **Canonical figures** for docs go to `assets/<project>/` — not here
5. **Team share** → promote to Google Drive after review; link from project intro
6. Contents are **gitignored** except this intro file
7. Evening batch may propose promotions out of Black Hole; you approve

## Not a trash folder

Black Hole is a **staging bay**, not deletion. Review → promote to project / Drive → or delete when done.

_Avoid:_ `output/`, `tmp/`, scattering builds at vault root
