# Vault Map

Three buckets (ACE) + the machine layer. Navigate here instead of searching.

## AIOS/ — the machine's manuals (portable, tool-agnostic)
- `MI.md` — the operating contract (identity, how to work, memory engine, save rule). Read first.
- `Vault Map.md` — this file.
- `Skill Map.md` — what skills exist and when to use each.

## System/ — the brain
- `SOUL.md` — Charlotte's voice (hot).
- `MEMORY.md` — `## Facts` + `## Profile` (hot, capped).
- `VOICES.md` — named personality overlays (deep; loaded when a voice is named).
- `Recall.md` — durable learnings (deep, grep on demand).
- `Patterns.md` — durable personality profile (deep, grep on demand).
- `The Curator.md` — the self-recursion mechanism (when present).

## ATLAS/ — knowledge, skills, reference (the "how")
- `Skills/` — all skills, by domain (Marketing, Content, Learning & Education Systems, Ashes Voices, Infrastructure & Tools). The interface is the Skill Map, not the folder tree.
- `Workflows/` — multi-skill sequences (Launch a Webinar Funnel, Build an Email Campaign, Design a Welcome Sequence, Write a Newsletter, Route Capture).
- `Reference/` — notes, ideas, sourcebooks.
- `Protocols.md` — the operating procedures (reflection loop, capture routing, recording rules/prompts, maintenance, the `{}` note convention).

## CALENDAR/ — time-based (the "when")
- `Daily/` — daily logs (`YYYY-MM-DD.md`) + the Que Routing Log.
- `Weeks/` — raw weekly tape (`Week [ISO].md`). Retained, not auto-read; pulled for playback.
- `Goals/` — monthly goals + `[C] RGS.md` + RGS full details (the strategy layer).
- `Archive/` — decayed patterns + old weeks. Not auto-read.
- `History/` — saved transcripts/conversations (Chronicler; saved only on command). When present.

## EFFORTS/ — work (the "what")
- `Active/` — active projects. Each holds its own `00 Introduction to [Project].md` (that project's README) + a Brain Dump.
- `Archive/` — completed projects.
- `Inbox/` — `00 Dispatch.md`, the in-session capture surface.

## Navigation rules
1. **Specific file/skill/project named** → jump straight in (use Skill Map for skills, EFFORTS/Active for projects).
2. **Domain named** → the Skill Map's section for it.
3. **Project named** → that project's intro + Brain Dump in `EFFORTS/Active/`.
4. Read introductions first. Follow references one level at a time.

## External
- Notion "The Que" — Ash's walk-away capture surface. DB URL lives in `ATLAS/Workflows/Route Capture.md`. Routed by the daily run; see Protocols.

## Maintenance
Added/renamed/deleted a file → update the one relevant line here or in the Skill Map. No counts, no per-folder intros, no separate index. That is the whole sync burden.
