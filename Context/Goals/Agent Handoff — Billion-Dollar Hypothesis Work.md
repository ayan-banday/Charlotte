## Founder–Investor Source Book v2 — Agent Must Know

**What it is:** A reasoning book (Chapters 1–12), not a workbook. Models investor-quality decisions from incomplete evidence. Uses **FDT (founder decision-transfer for agencies)** as a continuous live **Probe** case throughout.

**Evidence tags (use in all reasoning):**
- **[Fact]** — externally verifiable or customer-observed
- **[Inference]** — conclusion from specified facts
- **[Hypothesis]** — claim + decisive test
- **[Story]** — attractive assertion without sufficient evidence

**Decision labels:** Pursue / Probe / Pass (Pass on VC ≠ pass on company)

### Chapter Map

| Ch | Decision | Core lesson |
|---|---|---|
| 1 | Venture-scale or good business? | Power laws = portfolio fact. TAM ≠ enterprise value. Need nonlinear mechanism + bridge asset. Three revenue models. Disproof condition required. |
| 2 | Structural change? | Change → capability → behavior → economic value. Four-link chain. AI is enabler, not opportunity alone. Rumelt kernel. |
| 3 | Market size / value pools? | Start from P&L/risk event. Beachhead ≠ venture outcome. Expansion needs named bridge (buyer, workflow, data, integration). |
| 4 | Customer / painful workflow? | Roles: user, champion, buyer, approver, gatekeeper, risk owner. Six workflow properties. Reconstruction > opinions. Bottleneck may be authority, not knowledge. |
| 5 | Problem real enough? | Evidence ladder 0–6. Past behavior, artifacts, commitment. Decision record after every 3 interviews. |
| 6 | Evidence → strategy? | Diagnosis, guiding policy, coherent actions, explicit "not now" list. Initial monopoly = dense reachable cluster + shared workflow. |
| 7 | Radically better? | Value chain: behavior → workflow → outcome → buyer value. Primary metric + guardrails. Shadow mode before live. Paid sprint with predeclared kill threshold. |
| 8 | Repeatable reach? | Bullseye: 3 channel tests max. Reach → conversation → commitment → paid. Diagnostic outreach, not demo pitches. |
| 9 | Pay enough repeatedly? | Price = economic claim. Value capture ≠ time saved. Sprint → recurring only after behavioral result. Unit economics falsification. |
| 10 | Compounding advantage? | Data asset ≠ moat. Test vs generic AI baseline on 20–30 historical cases. Workflow embed + local outcome loop > cross-customer network story. |
| 11 | Investor belief / raise? | Capital buys de-risking of specific uncertainty. Belief chain with evidence column. Seed = Probe until paid outcome. |
| 12 | Kill experiments? | Predeclared thresholds. 4-week sprint design. Pre-mortem. Recurring 2–6 week decision memo. |

## Verification Protocol (How to Test the Hypothesis)

Run in order. Do not skip upstream steps.

**Phase 1 — Reconstruction (Ch 4/5)**
- 8–10 interviews, no product pitch
- Prompt: "Walk me through the last time your team waited on you before a client-facing decision."
- Stop rule: <3/10 recurring cases + artifact access → Pass or change ICP

**Phase 2 — Baseline audit (Ch 7)**
- 20 comparable historical cases from one firm
- Measure: founder touches, turnaround, rework, margin exceptions
- Primary metric + guardrails declared before live test

**Phase 3 — Generic AI benchmark (Ch 10)**
- 20–30 historical cases: current process vs generic AI vs your system
- Score: citation accuracy, appropriate escalation, resolution quality
- Kill if no measurable delta

**Phase 4 — Paid sprint (Ch 9/12)**
- 4 weeks, bounded scope, price stated upfront
- Shadow mode before guided live mode
- Continuation price decided before final review
- Pursue productization only if 2/3 similar firms pay to continue AND implementation <12 hrs/account

## Billion-Dollar Logic Template (Apply to Any Hypothesis)

```text
Outcome:     One falsifiable extraordinary end-state sentence
Revenue:     Accounts × pricing unit × retention/expansion × margin
Nonlinearity: ≥1 of: workflow embed, outcome loop, productized distribution, scale economies
Wedge:       Narrow segment + recurring trigger + bounded workflow
Bridge:      Named asset per expansion arrow (not "adjacent")
Disproof:    Fact that collapses the outlier case
Verdict:     Pursue / Probe / Pass
```
