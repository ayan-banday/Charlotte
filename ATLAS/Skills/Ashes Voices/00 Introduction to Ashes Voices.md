# Ashes Voices

Self-contained voice profiles for Ash Banday. Each profile holds everything needed to write in voice with no additional context. These are directly usable by any AI tool to produce on-brand writing.

## Voice Profiles in This Domain

See [[Skills Index]] for complete list. Organized by: Newsletter Voice, Substack Voice.

**Newsletter Voice** — rawer, narrative-forward, framework-focused, longer-form storytelling
**Substack Voice** — direct opinion, shorter-form thought leadership, philosophical confessing, punchier cadence

## How to Use

Paste the entire voice profile into any AI tool. Then instruct: "Write in my [voice type]. Use the guide above." That's it. No additional context needed.
