# Skills Library

This library is now organized into 5 operating domains so each skill is easier to find and trigger during execution.

## Domain Structure

- `Marketing/` - conversion, offer positioning, webinar architecture, and sales messaging.
- `Content/` - writing, production, and idea development for perspective-driven content.
- `Learning & Education Systems/` - teaching systems, exam frameworks, and Hyperframes stacks.
- `Ashes Voices/` - self-contained voice profiles for Ash Banday (newsletter and Substack voices).
- `Infrastructure & Tools/` - document automation, utilities, and system support skills.

## How To Navigate

- Start with `Skills Index.md` for a full searchable catalog.
- Use domain introductions (`00 Introduction ...`) to choose the right skill quickly.
- Open the skill file and run the instructions as-is.

## Naming Logic

All active skills follow a consistent naming system:

- lowercase + hyphenated
- descriptive in 2-4 words
- action-object, creator-function, or category-tool naming patterns

## Obsidian Linking Rules

- Use exact skill names for internal links, e.g. `[[webinar-planning]]`.
- Keep links file-name aligned after every rename.
- Prefer linking to skill files, not old legacy folders.
