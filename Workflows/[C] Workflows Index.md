# Workflows Index

Rules-based categorization. Organized by Core Capability → Domain → Problem Solved.

---

## Categorization Rules

**Core Capability:** What outcome or ability does this create?
- Ask: "What can I do after this workflow that I couldn't do before?"

**Domain:** In what areas of business/life does this apply?
- Ask: "Where will I use this?"

**Problem Solved:** What specific problem or desired outcome?
- Ask: "What's the concrete result?"

## How to Add a New Workflow

When you say "Record the workflow," I:
1. Ask you to name the problem it solves
2. Determine Core Capability → Domain → Problem Solved
3. Create a new file: `[[Workflow Name]].md`
4. Document the skill sequence and any variations
5. Add it to this index

**You decide** what gets recorded. Only record when you ask.
