# Workflows

Action sequences combining multiple skills toward complete end goals.

**Purpose:** When a single skill isn't enough, workflows chain skills together into unified processes. Each workflow solves a specific problem and produces a concrete deliverable.

---

## Structure of a Workflow

Each workflow is one file: `[Workflow Name].md`

Contains:
- Problem statement (what's being solved)
- Step-by-step skill sequence
- When to use it
- Variations or branches (if applicable)

## How to Create a New Workflow

When you identify a repeatable process combining multiple skills:

1. Say "Record this workflow"
2. Name the problem it solves
3. I'll ask for: goal, skills used, and execution steps
4. I create the workflow file
5. I add it to the index

You decide what gets recorded. Only record when you ask.
