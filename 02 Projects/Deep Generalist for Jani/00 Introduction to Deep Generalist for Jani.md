# Deep Generalist for Jani

Turning Jani into a Deep Generalist — someone who is never caught off guard by life. Cognitively capable, psychologically resilient, thoroughly educated in the domains that matter.

**Status:** Phase 1 — Encoding in progress

---

## Vision

Become a Deep Generalist. Able to pursue a big scary goal and adapt when plans break. Never reactive. Always capable.

---

## Objectives

### Objective 1 — Encoding

Build the core skill of deep processing using medicine exams as the forcing function.

- **Core Skill:** Deep processing — the ability to learn anything fast and retain it under pressure
- **Forcing Function:** Med school exams. Real stakes. Real deadlines. Real feedback.
- **Deliverable:** [[Meta-Level Examiners Guide]] — the full map of how Jani gets tested and how we attack each exam type

**Why medicine as the forcing function:**
High volume, high complexity, high stakes. If Jani can build a system that works here, it works anywhere. This is how the methodology gets forged, not theorised.

---

### Objective 2 — Main Program (Phase 2)

One big scary goal. A series of mountains. Each mountain is a threshold guardian — a real-world boss to kill before moving forward.

**To be built once Objective 1 is underway.**

The loop:
1. Run into a problem
2. Develop the solution (mental models, heartset work, iterate)
3. Kill the threshold guardian
4. Extract the philosophy and meaning
5. Next mountain appears

**Domains that run parallel:** Business + Medicine

**Continuous foundation (non-negotiable):**
- **Healthset** — physical capacity as the hardware
- **Soulset** — purpose, philosophy, meaning
- **Exam Backcasting Methods** — applied continuously, refined as demands grow
