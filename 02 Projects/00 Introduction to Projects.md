# Projects Folder Map

**Purpose:** Active projects that are moving toward completion.

**Each project:** One folder with consistent structure for organization and AI navigation.

---

## Structure of a Project Folder

Each project folder (`/02 Projects/[Project Name]/`) starts with:

```
00 Introduction to [Project Name].md    ← Project context, why it exists, current status
01 Brain Dump for [Project Name].md     ← Your thinking space. Raw notes, questions, blockers.
[Other files as needed]                 ← Created only when you decide they're needed
```

**You create what you need.** Start with Introduction + Brain Dump. Add other files as the project requires.

---

## How To Create a New Project

1. Create folder: `/02 Projects/[Project Name]/`
2. Create file: `00 Introduction to [Project Name].md` with this structure:
3. Create file: `01 Brain Dump for [Project Name].md` — Empty, ready for your thinking
4. That's it. Add other files only when needed.

## How Claude Navigates Projects

When you ask for help with a project:

1. Claude reads `00 Introduction to [Project Name].md` to understand context
2. Claude checks `01 Brain Dump for [Project Name].md` for your current thinking
3. Claude follows any instructions in the Introduction file
4. Claude doesn't create files, doesn't assume structure, doesn't populate templates
5. Claude only does what you explicitly ask

**Key principle:** You decide what files exist. Claude reads what exists and follows instructions in the Introduction file.
